# เปิดระบบแบบคลิกเดียว

ดับเบิลคลิก `Start-ICU-System.cmd` เพื่อเปิดระบบทั้งหมดครั้งเดียว

ตัวเปิดระบบจะตรวจและจัดการสิ่งต่อไปนี้ตามลำดับ:

1. ตรวจ Python environment, Node modules และ PostgreSQL tools
2. เปิด PostgreSQL ใน workspace หากยังไม่ทำงาน
3. เปิด Backend หาก health check ไม่ผ่าน แล้วรอจนพร้อม
4. เปิด Frontend หากยังไม่ทำงาน แล้วรอจนหน้าเว็บตอบได้
5. เปิดเว็บที่ `http://127.0.0.1:5174` อัตโนมัติ
6. เปิด Expo สำหรับ Expo Go หากยังไม่ทำงาน เพื่อสแกน QR

เพื่อป้องกันข้อมูล pilot ตัวเปิดระบบจะ **ไม่** ปิดโปรแกรมที่ไม่รู้จักซึ่งครอบครองพอร์ต 8001 และจะไม่แก้ไข/ล้างข้อมูลตารางเวรหรือฐานข้อมูลโดยอัตโนมัติ หากพบปัญหาจะบอกสาเหตุไว้บนหน้าต่างแทน
